A quick guide to Result Desk

  1. Upload a PDF or image. We read embedded PDF text when available; otherwise, local OCR reads the image.
  2. Check the highlighted columns. Green is the roll, amber is the marks column. Drag new regions and re-extract if needed.
  3. Review each student. Click a result to see the original row. Edit values, mark a reading verified, or press Enter or R on a selected row. Missing marks stay blank.
  4. Build your spreadsheet. Click Choose columns & preview. Select source columns or draw custom ones, rename headings, move columns with handles or arrows, and edit cells.
  5. Save or export. Save layout keeps your preview for later. Export Excel downloads those selected headings, values, and column order, with review notes on a separate sheet. CSV is in the more menu.

Main review edits save automatically. Spreadsheet drafts save when you click Save layout or Export. Keep the local server running while you work. Printed, upright tables work best.
